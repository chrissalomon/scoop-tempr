# Scoop bucket for the Tempr CLI

```powershell
scoop bucket add tempr https://github.com/chrissalomon/scoop-tempr
scoop install tempr
```

Updates with `scoop update tempr`. See [temprhq.io/cli](https://temprhq.io/cli) for what the CLI
does and [the docs](https://temprhq.io/docs/quickstart-cli) to get started.
